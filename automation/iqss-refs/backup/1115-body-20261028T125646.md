## Summary

Every legacy JSF page carries "User Guide" and "Support" links in the site header, and "Support" opens a contact form addressed to the installation's support address. The new frontend's header has neither — it shows only Language, Add Data and the user menu when signed in, or Language and Log In when anonymous. There is no way to reach installation support, or the user guide, from anywhere in the SPA.

## Legacy JSF behavior

`dataverse_header.xhtml` renders "Add Data", "Search", "User Guide" and "Support" alongside the user menu. "Support" is a command link (`headerSupportLink`) that opens the shared contact dialog (`PF('contactForm').show()`), pre-addressed to installation support rather than to a specific collection. Both links appear on every page, including the account pages, and for anonymous visitors.

### Steps to observe

1. Open the legacy JSF app (http://localhost:8080).
2. Observe "User Guide" and "Support" in the top-right header, on any page — including Account -> Account Information.
3. Click "Support" and observe the contact form for installation support.

## New frontend behavior

`Header.tsx` renders the brand, a `LanguageSwitcher`, and then either `LoggedInHeaderActions` (Add Data + user menu) or a single OIDC "Log In" button. Nothing else. The SPA does have a contact modal, but it is the per-collection "Email Collection Contact" reached from a collection's "Contact" button — that addresses the collection's contacts, not installation support, and it is not reachable from the account pages or from a dataset.

### Steps to reproduce

1. Open the modern frontend (http://localhost:8000/modern), signed in or not.
2. Inspect the header: only Language, Add Data and the user menu (or Log In).
3. Go to `/modern/account?tab=accountInformation` and confirm there is no Support or User Guide link anywhere on the page.

## Expected behavior

The new frontend should offer an installation-level support contact and a user-guide link that are reachable from any page, as legacy's header does — so a user who is stuck, or whose account details are wrong, has a route to ask for help.

## Current behavior

Absent. The only contact affordance in the SPA is the per-collection "Email Collection Contact" modal, which has a different recipient and is not available from account or dataset pages. Users have no in-app path to installation support and no link to the documentation.

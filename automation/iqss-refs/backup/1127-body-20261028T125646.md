## Summary

Legacy JSF lets a dataset editor create a shareable review link for an unpublished draft — called "Preview URL" in 6.11 (formerly "Private URL") — then copy it or disable it, with an anonymized variant when the installation configures anonymized fields. In the new frontend the dataset Edit menu still lists "Private URL", but the entry is wired to the shared not-implemented handler, so no review link can be created, copied or disabled.

## Legacy JSF behavior

Edit Dataset -> "Preview URL" opens the "Unpublished Dataset Preview URL" dialog. For a draft it offers **Create General Preview URL**; once created it shows the generated `previewurl.xhtml?token=...` link with **Copy to Clipboard** and **Disable General Preview URL**. For a published version it refuses with "Preview URL can only be used with unpublished versions of datasets." Only one Preview URL can be active per draft.

### Steps to observe

1. Log into the legacy JSF app (http://localhost:8080) as `dataverseAdmin`.
2. Open an **unpublished draft** dataset (this review used `doi:10.5072/FK2/8PW3WO`).
3. Open the "Edit Dataset" dropdown and select "Preview URL".
4. Click "Create General Preview URL" and observe the generated link with "Copy to Clipboard" and "Disable General Preview URL".

## New frontend behavior

`EditDatasetMenu.tsx` lists the entry as `EditDatasetMenuItems.PRIVATE_URL`, shown when the user can manage dataset or file permissions, and its handler is:

```tsx
if (eventKey === EditDatasetMenuItems.PRIVATE_URL) {
  showModal()
  return
}
```

So it opens the "Not Implemented" modal. The SPA *can consume* a preview URL token (`getDatasetByPrivateUrlToken`, anonymized view in `DatasetFactory.tsx`), but it provides no way to create, copy or disable one.

### Steps to reproduce

1. Log into the modern frontend (http://localhost:8000/modern) as `dataverseAdmin`.
2. Open an unpublished draft dataset you can edit and open the "Edit Dataset" dropdown.
3. Select "Private URL".
4. Observe the "Not Implemented" modal. No link is created and none can be copied or disabled.

## Expected behavior

A user who can manage dataset permissions should be able to create a preview/private URL for a draft from the new frontend, copy it, and disable it — plus create the anonymized variant where the installation enables it — and be told clearly that the feature applies only to unpublished versions.

## Current behavior

The menu entry is present but non-functional — it opens the generic "Not Implemented" modal. Creating a review link requires leaving the SPA for the legacy JSF page, even though the SPA already understands the resulting token.

- [ ] Only users who can manage dataset permissions see the entry
